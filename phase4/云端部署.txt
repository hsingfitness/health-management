3. PostgreSQL + FastAPI

version: "3.9"


services:


  backend:

    build: .

    container_name: health_ai_api


    ports:

      - "8000:8000"


    env_file:

      - .env


    depends_on:

      - postgres



  postgres:


    image:

      postgres:16


    container_name:

      health_ai_db


    environment:


      POSTGRES_USER:

        health_admin


      POSTGRES_PASSWORD:

        password


      POSTGRES_DB:

        health_ai



    volumes:


      - postgres_data:/var/lib/postgresql/data



volumes:

  postgres_data:

5. 图片存储升级

本地：

storage/images/

云端：

AWS S3

bucket:

health-ai-images

    |
    |
    ├── customer001
    |
    ├── customer002

安装：

pip install boto3
cloud_storage.py
import boto3


s3=boto3.client(
    "s3"
)



def upload_image(

    file,

    filename

):


    s3.upload_fileobj(

        file,

        "health-ai-images",

        filename

    )


    return (

    f"s3://health-ai-images/{filename}"

    )

以后：

本地保存路径

↓

S3 URL

数据库不用改变：

Image.file_path

仍然保存地址。

8. 数据库迁移

不要使用：

Base.metadata.create_all()

生产环境使用：

Alembic

安装：

pip install alembic

初始化：

alembic init migrations

以后修改：

例如：

增加：

AI_score = Column(Integer)

执行：

alembic revision --autogenerate \
-m "add AI score"


alembic upgrade head

数据库自动升级。
